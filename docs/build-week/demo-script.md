# Demo Script

## Phase 0 demo

1. Open the Trailie Crew landing page.
2. Show the responsive monochrome shell, wordmark, tagline, provenance label, and Build Week category.
3. Toggle between light and dark themes with keyboard focus visible.
4. Explain that Create a Trip and Join a Trip are intentionally non-functional in Phase 0.
5. Show the pnpm workspace boundaries and CI quality gates.

## Planned product demo

The eventual Build Week demo is expected to show friends creating or joining a Trip without an intake form, discussing a trip in shared chat, observing that Trailie remains silent during ordinary conversation, explicitly invoking `@Trailie`, approving an itinerary request, and revising or exporting a validated itinerary.

That planned flow is not implemented yet and must be revised to match verified functionality before submission.
